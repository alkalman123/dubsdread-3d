About Crux

Printed by hand, one bed at a time.

Crux is a small-batch 3D-printing studio in Chicago, making gear-storage pieces for climbers — starting with the one we wished existed.

How it started

A gear bench that stayed a mess.

Every session ended the same way: chalk bag in one spot, keys somewhere else, sunglasses folded under a crash pad. Nothing about climbing gear is small enough to stay put and expensive enough to warrant a proper organizer — so we designed one and printed it ourselves.

The Rock Ring is the first shape off the plate: one block, two open ports, no wall or hardware required. V1, because it won't be the last.

Small on purpose

No warehouse, no pallets of stock. Every order is a print job, queued and run to order — which means colors never really go "out of stock."

Designed for real gear

The design started from an actual gear bench, not a mood board. It changes when it needs to — this is V1 for a reason.

Honest about the medium

It's a 3D print, not an injection-molded product — layer lines and all. We'd rather you know that before it arrives than after.
